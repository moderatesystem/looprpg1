# 参考ゲームのバトル情報（2026-11-20 調査）

目的: バフ・デバフ・状態異常・回復・解除の設計材料を集める。
対象: Slay the Spire / Darkest Dungeon / Etrian Odyssey / Hades（＋DQ・FFの命名）。
数値は各Wikiの記載。作品・バージョンで変わるため、採用時に再確認する。

---

## 1. Slay the Spire

**構造**: 1ターンに複数カード。状態は「強度（Intensity）」と「持続（Duration）」に分かれる。

| 状態 | 効果 | 重複 |
|---|---|---|
| Vulnerable（脆弱） | **被ダメ +50%**（Attackのみ。毒・オーブ・棘は対象外） | 持続のみ加算（強度は固定） |
| Weak（脱力） | **与ダメ -25%** | 持続のみ加算 |
| Frail | ブロック獲得 -25% | 持続のみ |
| Poison | ターン開始時に**Xダメージ→X-1**。ブロック無視 | 強度＋持続 |
| Strength | 攻撃1ヒットごとに**+X**（多段に乗る） | 強度 |
| Artifact | **デバフをX回無効** | カウンタ |
| Intangible | 被ダメとHP減少を**1に固定**（Xターン） | 持続 |
| Thorns | 攻撃されたら**X反射** | 強度 |
| Metallicize / Plated Armor | ターン終わりに**ブロック+X**（Platedは被弾で-1） | 強度 |
| Regenerate | ターン終わりに**HP+X回復** | 強度 |

**重要な仕様**
- 計算順: **Strength（足し算）→ 脆弱/脱力（掛け算）→ 切り捨て**。
  例: 6ダメージ +筋力2 → 脆弱で (6+2)×1.5 = 12。
- 脱力は切り捨ての影響で、多段攻撃に強く出る（5×3 → 3×3 で実質-40%）。
- 毒は付与時ではなく**ターン開始時**に発動し、毎ターン1ずつ減る。
- アーティファクトは「1回の付与」を丸ごと無効化する。

**このゲームへの示唆**: 状態を「強度」と「持続」に分けると、表示とバランスが整理できる。

## 2. Darkest Dungeon

**構造**: 持続ターン方式。状態は個別にスタックし、それぞれの期限で切れる。

| 状態 | 効果 | 持続・備考 |
|---|---|---|
| Bleed / Blight | ターン開始時に**強度ぶんダメージ**。PROT（防御）無視 | 既定3ターン。会心で+2ターン |
| Stun | **1ターン行動不能** | 解除後、**スタン耐性+50%**（連続スタン防止、100%・150%と累積） |
| Mark | 単体では無効果。**印付きへのスキルが大ダメージ**（+50〜100%等） | 3ターン。**耐性不可**。敵は印付きを67〜87%で狙う |
| Guard | **直接攻撃を自分へ引き寄せる**（ダメージ・デバフごと） | 3ターン。範囲攻撃は貫通。スタンで解除 |
| Riposte | 攻撃されたら**反撃** | 2〜3ターン |

**重要な仕様**
- DoTは**防御を無視**する（硬い敵への回答）。
- スタンは**連続で決まらない**（耐性が累積）。
- マークは「単体では何も起きないが、専用スキルが爆発する」条件トリガー。

**このゲームへの示唆**: 「麻痺は1回まで＋解除後は耐性」、DoTは防御無視、マークは斥候の印として使える。

## 3. Etrian Odyssey

**構造**: バフ・デバフの**枠数と減衰**で数字を制御する。

| ルール | 内容 |
|---|---|
| 枠 | **バフ3・デバフ3**まで。4つ目は最も古いものが消える |
| 相反 | 攻撃↑と攻撃↓など**逆極性は打ち消し合う**（強さに関係なく） |
| 同源 | **同じスキルは重ならない**（持続リセットのみ）。別スキルなら重なる |
| 減衰（EO2U以降） | 同カテゴリ2つ目は**60%**、3つ目**20%**、4つ目**0%** |
| 持続 | ターン終わりに1減る（表示より実質1ターン長い） |
| 状態異常 | **1体につき1つ**。上書き。スタックしない |

**このゲームへの示唆**: バフを積ませたいなら**減衰**を入れる。入れないなら枠を3に絞る。

## 4. Hades

**構造**: 状態異常は短時間・高頻度。ボスには弱体化して乗る。

| 状態 | 効果 |
|---|---|
| Weak | **与ダメ -30%**（Hades 1）。最低4秒 |
| Hangover | 3秒間、**0.2秒ごとにDoT**（移動中） |
| Chill | 移動速度低下（スタックで増加） |
| Jolted | 攻撃すると追加ダメージ |
| Exposed | 被ダメ増加（条件付き） |

**重要な仕様**
- **ボスは状態の効果時間が短く、効果も弱い**。
- Duo Boon（2神の状態を同時に要求）＝**組み合わせで解放される強化**。

**このゲームへの示唆**: ボスには「状態が半分の時間しか乗らない」を入れれば、麻痺や脆弱の永久化を防げる。

## 7. このゲーム用の推奨セット（8個）

短期決戦（1戦3〜5R）に合わせ、持続は2〜3R。

| 効果 | 種別 | 数値 | 持続 | 参考 |
|---|---|---|---|---|
| 攻撃上昇 | バフ | 与ダメ +25% | 3R | StS Strength相当 |
| 防御 | バフ | 被ダメ -30% | 2R | DD Guardの簡略版 |
| 再生 | バフ | R終わり HP+8 | 3R | StS Regenerate |
| 毒 | 状態異常 | 8ダメ/R、防御無視 | 3R | StS Poison |
| 感電 | デバフ | 被ダメ +25% | 2R | 独自（多段に強い） |
| 脆弱 | デバフ | 被ダメ +30% | 2R | StS Vulnerableの弱体版 |
| 脱力 | デバフ | 与ダメ -25% | 2R | StS Weak |
| 麻痺 | 状態異常 | 1回行動不能 | 1R | DD Stun＋耐性 |

**ルール**
- バフ3枠・デバフ3枠。4つ目は古い順に消える（EO）。
- 同種は上書き（持続リセット）。**加算しない**。
- 逆極性（攻撃↑と攻撃↓）は打ち消し（EO）。
- ボスは状態の**持続を半分**（Hades）。
- 解除（クレンズ）は**1戦1回**。
- 計算順: **装備の足し算 → バフ/デバフの掛け算 → 会心 → 切り捨て**（StS）。

**状態異常を「条件」にする**（DDのマーク、StSの毒→触媒）
- 毒 → 爆発（毒を消費して大ダメージ）
- 感電 → 多段・大技が伸びる
- 脆弱 → 大技の前振り
- 麻痺 → 危険な首を止める
