# バトルシステム設計（2026-11-25 確定版）

JRPGの世界観＋Slay the Spire系の戦闘＋レベル成長。
参考: Slay the Spire / Darkest Dungeon / Etrian Odyssey / Hades / アリアンロッドRPG（やらない夫MMスレ）。

目標: **1遠征10分・1戦3〜6ラウンド・防御と回復に意味がある**。

---

## 1. 基本

| 項目 | 内容 |
|---|---|
| 形式 | 自キャラ**3体** vs 敵1〜3体 |
| 行動順 | **味方 → 敵** の固定（素早さなし） |
| 1ラウンド | **味方ターン ＋ 敵ターン** |
| 各ターン | **セットアップ → メイン → クリーンアップ** |
| エネルギー | **なし**。各キャラ1ターン1行動 |

---

## 2. ラウンド構造

```
ラウンド N
├─ 味方ターン
│   ├ セットアップ
│   ├ 指揮官
│   ├ メイン
│   └ クリーンアップ（敵のブロックを0）
└─ 敵ターン
    ├ セットアップ
    ├ メイン
    └ クリーンアップ（味方のブロックを0／次の意図を決定）
```

| フェーズ | 味方 | 敵 |
|---|---|---|
| セットアップ | レリック発火／麻痺などの回復判定／**敵の意図を確認** | 自分のセットアップ効果／行動の確定 |
| **指揮官** | **命令を1回**（意気昂揚は毎回、他は1戦1回） | — |
| メイン | 3人が1行動ずつ（**行動順は選択可**） | 確定した意図どおりに行動 |
| クリーンアップ | 毒・燃焼ダメージ／バフ・デバフ -1／気絶確定／**敵ブロックを0** | 同左／**味方ブロックを0**／**次の意図を決定** |

- 敵の意図は**敵クリーンアップで決定**し、次の味方セットアップで公開される
- 付与したターンもバフの残りターンに数える（2Tなら「今＋次」）

---

## 3. ブロック

- ブロックは**加算**。ダメージはブロック → HPの順に受ける
- **相手の次のクリーンアップで0**（自分のクリーンアップでは消さない）

```
R2 味方メイン        ガルドがブロック10
R2 味方クリーンアップ  10のまま
R2 敵メイン          大技24 → 10軽減、14被弾
R2 敵クリーンアップ   味方のブロックを0
R3 味方セットアップ   ブロック0
```

敵のブロックも同様: 敵メインで得たブロックは味方メインを守り、**味方クリーンアップ**で0。

---

## 4. 自キャラ（3体）

| 枠 | 役割 | HP（初期案） | 主な行動 |
|---|---|---|---|
| 盾 | 挑発・かばう・防御 | 55 | 敵の対象を自分に集める／ブロック |
| 火力 | 単体・連撃・必殺 | 38 | 大ダメージ。低HP |
| 支援 | 回復・強化・解除 | 32 | ヒール／バフ／状態異常回復 |

- **気絶**: HP0で行動不能。**戦闘後にHP1で復帰**。3人全滅で敗北
- 対象は自動（最も減っている敵／味方）。タップで変更可
- **行動順はプレイヤーが選べる**（味方をタップすると、そのキャラを先頭に繰り上げる）

---

## 5. 行動（1キャラ1ターン1回）

| 行動 | 内容 | 制限 |
|---|---|---|
| 通常攻撃 | 単体ダメージ | 無制限 |
| 技 | 役割ごとの固有技 | **1〜2回/戦** |
| 防御 | ブロックを得る | 無制限 |
| ためる | **テンション+2**＋ブロック少量 | 無制限 |

- **エネルギーは使わない**。行動数（3）が実質の予算
- 強い技は「使用回数」と「テンション」で制限する

### 行動選択 → 対象選択

行動を選んでから対象を選ぶ。対象不要（防御・ためる）は即実行。

- **期待**（行動ボタン）: 自分の火力のみ。防御・ブロック・弱点・会心を含めない
- **予想**（対象選択）: 防御・ブロック・弱点を反映した、実際に入るHPダメージ
- 会心は確率なので別表示（通常値に混ぜない）
- 戻るで行動選択に戻れる

### 指揮官命令（指揮官フェーズに1回）

指揮官は味方より先に動く。命令はキャラの行動を消費せず、1フェーズに1回。

| 命令 | 効果 | 使用 |
|---|---|---|
| 意気昂揚 | 指定キャラのテンション +1 | 毎ターン |
| 精密解析 | 対象の弱点を公開、次の攻撃 +20% | 1戦1回 |
| 絶対回避 | 指定キャラの次の被弾を1回無効 | 1戦1回 |
| 命令再起 | 指定キャラが追加で1行動 | 1戦1回 |
| 総員交代 | 控えと1人入れ替え | 未実装 |

命令はテンションを消費しない（使用回数で制限する）。

## 6. テンション

| 項目 | 内容 |
|---|---|
| 範囲 | **キャラごとに0〜6**（戦闘ごとにリセット） |
| 獲得 | ためる +2／被弾 +1（1R1回）／意気昂揚 +1 |
| 消費 | 必殺 3／大必殺 6 |
| 表示 | 各キャラのHP下に6ピップ |

**防御・ためるを「投資」に変える**のが目的。攻撃を捨てたターンが、必殺の準備になる。
支援が「ためる／意気昂揚」で火力に渡す**テンションコントローラー**の役割が生まれる。

> 仮決定: 個別ゲージ。UIが重ければ共有ゲージに変更可。

## 7. 状態異常・バフ

### 状態異常（5種）

| 状態 | 効果 | 処理 |
|---|---|---|
| 毒 | クリーンアップで8ダメージ | 3T |
| 麻痺 | 次の行動を1回スキップ。解除後は耐性+50% | 1T |
| **封印** | **技スロット1つを2T使用不可** | 2T |
| 凍結 | 与ダメ -25%。**火属性で解除** | 2T |
| 混乱 | 次の行動がランダム対象になる | 1T |

### 状態変化（バフ4種）

| 状態 | 効果 |
|---|---|
| 貫通 | ブロックを無視 |
| リホイミ | クリーンアップでHP+6 |
| 拒絶 | 被弾1回を無効＋テンション+1 |
| 精神統一 | 次の行動を2回発動 |

- 表示は**1キャラにつき最大3アイコン**、残りターン数を併記
- 行動不能系は重ねがけしない（麻痺は耐性が累積）

## 8. ダメージ計算

```
ダメージ = max(1, (攻撃力 + 装備) × 倍率 - 防御力)
→ ブロックが先に吸収 → 超過分がHPへ
```

- 計算順: **足し算 → 掛け算 → 切り捨て**（StS準拠）
- 会心: 15%で **×1.8**
- 倍率の例: 攻撃上昇 ×1.25／脱力 ×0.75／脆弱 ×1.30／感電 ×1.25
- 貫通はブロックを無視

---

## 9. 敵の意図

- 表示: **行動の種類＋数値＋付帯**（攻撃12／大技24／毒付与／防御）
- 見えるのは**今ターンだけ**。次以降は不明
- 大技は**1ラウンド前に予告**（「首が息を吸っている」等）
- 斥候・精密解析で情報が増える

---

## 10. 遠征との接続

| 要素 | 内容 |
|---|---|
| HP | **遠征中は持ち越し**（戦闘後に全回復しない） |
| 泉 | 1遠征1回、+25% |
| 休憩ノード | 「回復」か「強化」の二択 |
| 気絶 | 戦闘後にHP1で復帰。全滅のみ敗北 |
| 回復 | 技は1〜2回/戦。自由回復はなし |
| 撤退 | いつでも可。持ち帰りが減る |

**回復の希少性**が防御を意味あるものにする。

## 13. 試作の実装範囲（`public/proto.html`）

**実装済み**
- 3体・7フェーズ（セットアップ／指揮官／メイン／クリーンアップ × 味方・敵）・ブロックの相手クリーンアップ消去・敵意図・テンション
- 指揮官命令4種（意気昂揚／精密解析／絶対回避／命令再起）。味方対象はタップで選択
- **行動順の選択**（味方をタップで先頭へ）
- **期待／予想の2段階表示**（行動→対象選択）
- 毒・麻痺・封印、会心、使用回数、勝敗
- **効果音**（WebAudioの簡易シンセ、ミュート切替）
- **ログは残り領域を可変で使う**（「拡大」で全履歴）
- **選択肢の詳細ポップアップ**（説明・対象・使用回数・期待/会心）

**未実装（試作の範囲外）**
- 凍結・混乱・拒絶・精神統一・貫通、麻痺の耐性累積
- 気絶→戦闘後復帰（表示のみ）・総員交代
- レベルアップ、デッキ／ドラフト、装備
