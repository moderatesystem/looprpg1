# 素材採取・鍛冶システム設計（2026-10-06 設計のみ確定）

## 位置づけ
- DQ1からの分岐点を意図的に作る。本作の差別化は「特性3択」＋「集める楽しみ」の二本柱とする
- 目的1：洞窟に反復訪問の理由を作る（現状は宝箱1回＋ボス1回で用済み）
- 目的2：戦闘以外の成長手段（金策・装備）を増やし、小ループを太らせる

## 採取ルール
- 洞窟マップに銅鉱脈タイル `O` を3〜4箇所配置（凡例追加予定）
- 鉱脈は通行不可。隣接マスでEキーを押すと採取できる
- 採取した鉱脈はその入坑中は枯渇表示になる
- 洞窟に入り直すたびに全復活（宿屋・教会とは独立したリセット）
- 1回の採取で銅鉱石1〜2個（ランダム）

## 素材
- 第1弾：銅鉱石（copper）のみ
- 将来：鉄鉱石、銀、魔石を上位洞窟・高危険テリトリー用に拡張
- 所持は `player.mats = { copper: n }`。ステータス画面（Tキー）に表示、セーブ対象に含める

## 用途（Step1：売却のみ）
- 武器屋・鍛冶屋で1個15Gで売却できる
- 戦闘金策（スライム5G前後）とのバランス：洞窟の往復コスト（遭遇率12%・敵Lv+2）と見合う水準
- 売却UIは既存の宿屋・武器屋と同じZ/X選択式にする

## 用途（Step2：鍛冶クラフト）
- 新NPC「鍛冶屋」を街道の村 (14,7) に配置する（空きタイル確認済み）
- レシピ案：
  - 銅のつるぎ（ATK+3）＝ 銅3個
  - 銅のたて（守備+3）＝ 銅2個
- クラフト品は店売り品（どうのつるぎATK+2等）と競合しない強さにする
- UIは武器屋の在庫式（stock配列）を流用し、素材不足時は断り文を出す

## バランス指針
- 銅1個15G、1入坑で平均4〜5個＝約60〜75G。宿1泊20G・てつのつるぎ120Gとの関係で2〜3入坑で1品の速度感
- 採取だけ回す放置稼ぎ防止：鉱脈は入坑ごと復活だが、洞窟内遭遇は回避不可の通常率とする

## 実装タスク分解
1. `dialogues.json`：洞窟マップに `O` 配置＋凡例、鍛冶屋NPC追加（Step2）
2. `state.js`：`player.mats`、`shopBought`流用の素材交換、在庫リセット（入坑時）
3. `DungeonScene.js`：隣接Eキー採取、枯渇表示、入坑リセット
4. `FieldScene.js`：売却・クラフト選択肢、ステータス表示は `statusUi.js` に素材行追加
5. `worldbase.md`：洞窟凡例に `O` を追記
