# プロジェクト概要（2026-10-03 再開版）

## キーコンセプト
- 何度でもプレイできる昔のRPGを提供する
- 作り込まれた感じ、テンポの良さ、なつかしさを重視する

## 昔のRPGとは
- ドラクエ１，２，３のようなイメージ
- まずは制作難易度的にドラクエ１を目指す
- 必須3要素：1対1コマンドバトル／広いマップを歩く感じ／町・NPC会話（全部入りで作る）

## 技術方針（2026-10-03 決定）
- Web (HTML/JS) + Phaser 3 継続（現 main ブランチ起点）
- `origin/working` の MapScene / tilemap 直読み方式は捨てる（失敗履歴として参照のみ）

## 育成方針（2026-10-03 決定）
- レベルアップ時に呪文を覚えるのではなく、特性を3つの中から1つ選ぶ形式にする
- 特性プール案20個あり。試作では8個に絞る
- 重ねがけ（スタック）ありを基本とし、上限あり特性は3択プールから除外する
- レアリティ演出は初期はなし。後から検討

## やらないこと（2026-10-03 確認）
- Loop Hero型（自動周回＋カード配置）への転換はしない
- 理由：元々作りたかったDQ1リスペクトから外れるため
- ただし seed 生成の考え方・特性取得タイミング等の部分流用は可
